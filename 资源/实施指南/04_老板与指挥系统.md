# 04. 老板与指挥系统

> 本章教你：创建玩家控制的良心老板，实现指挥范围机制

---

## 🎯 本章目标

1. 创建 Boss 类（玩家角色）
2. 实现键鼠移动控制
3. 实现指挥范围系统
4. 实现对员工下达指令

完成后：
- WASD/方向键移动老板
- 老板周围有可视化的指挥范围
- 可以选中范围内的员工并下达指令

---

## 📖 概念讲解：指挥系统

```
┌─────────────────────────────────────────────────────────┐
│                      战场                                │
│                                                         │
│      [员工A]                    [员工C]                  │
│            ╲                  ╱ (范围外，无法指挥)        │
│             ╲  指挥范围      ╱                           │
│              ╲ ┌────────┐  ╱                            │
│               ╲│        │╱                              │
│     [员工B] ──→│  老板  │                               │
│                │        │                               │
│                └────────┘                               │
│                                                         │
│  在指挥范围内的员工可以接收指令（跟随、攻击、防御等）       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 📝 第一步：创建 Boss 类

### 1.1 创建 Boss 脚本

1. 右键 `Assets/_Game/Scripts/Unit`
2. `Create > C# Script`
3. 命名为 `Boss`

### 1.2 编写代码

```csharp
using UnityEngine;
using CYFramework.Infrastructure;
using CYFramework.Core.Event;
using LiangXin.Data;
using LiangXin.Events;
using System.Collections.Generic;

namespace LiangXin.Unit
{
    /// <summary>
    /// 良心老板（玩家控制的角色）
    /// </summary>
    public class Boss : Unit
    {
        // ==================== 属性 ====================
        
        public override UnitFaction Faction => UnitFaction.Player;
        
        // ==================== 指挥系统 ====================
        
        [Header("指挥系统")]
        [Tooltip("基础指挥范围")]
        [SerializeField] private float _baseCommandRange = 3f;
        
        [Tooltip("当前指挥范围（可通过装备提升）")]
        [SerializeField] private float _commandRange = 3f;
        
        [Tooltip("指挥范围可视化")]
        [SerializeField] private SpriteRenderer _commandRangeIndicator;
        
        /// <summary>
        /// 当前指挥范围
        /// </summary>
        public float CommandRange => _commandRange;
        
        /// <summary>
        /// 范围内的员工列表
        /// </summary>
        private List<Employee> _employeesInRange = new List<Employee>();
        
        /// <summary>
        /// 当前选中的员工
        /// </summary>
        public Employee SelectedEmployee { get; private set; }
        
        // ==================== 输入 ====================
        
        private Vector2 _moveInput;
        
        // ==================== 死亡惩罚 ====================
        
        [Header("死亡惩罚")]
        [Tooltip("复活时间")]
        [SerializeField] private float _respawnTime = 3f;
        
        [Tooltip("死亡损失资金百分比")]
        [SerializeField] private float _goldLossPercent = 0.2f;
        
        private float _respawnTimer;
        
        // ==================== 生命周期 ====================
        
        protected override void Awake()
        {
            base.Awake();
            
            // 初始化指挥范围
            _commandRange = _baseCommandRange;
            UpdateCommandRangeVisual();
        }
        
        protected override void Update()
        {
            base.Update();
            
            if (CurrentState == UnitState.Dead)
            {
                // 复活计时
                _respawnTimer -= Time.deltaTime;
                if (_respawnTimer <= 0)
                {
                    Respawn();
                }
                return;
            }
            
            // 处理输入
            HandleInput();
            
            // 更新范围内的员工
            UpdateEmployeesInRange();
        }
        
        protected override void FixedUpdate()
        {
            if (!IsAlive) return;
            
            // 处理移动
            if (_moveInput.magnitude > 0.1f)
            {
                ProcessPlayerMovement();
            }
            else if (_rigidbody != null)
            {
                _rigidbody.velocity = Vector2.zero;
            }
        }
        
        // ==================== 输入处理 ====================
        
        /// <summary>
        /// 处理玩家输入
        /// </summary>
        private void HandleInput()
        {
            // 移动输入
            _moveInput = new Vector2(
                Input.GetAxisRaw("Horizontal"),
                Input.GetAxisRaw("Vertical")
            ).normalized;
            
            // 鼠标点击选中员工
            if (Input.GetMouseButtonDown(0))
            {
                TrySelectEmployee();
            }
            
            // 右键点击下达移动指令
            if (Input.GetMouseButtonDown(1) && SelectedEmployee != null)
            {
                IssueMovementCommand();
            }
            
            // 快捷键指令
            HandleCommandInput();
        }
        
        /// <summary>
        /// 处理指令快捷键
        /// </summary>
        private void HandleCommandInput()
        {
            if (SelectedEmployee == null) return;
            
            // F - 跟随
            if (Input.GetKeyDown(KeyCode.F))
            {
                IssueCommand(SelectedEmployee, CommandType.Follow);
            }
            // D - 防御
            else if (Input.GetKeyDown(KeyCode.D))
            {
                IssueCommand(SelectedEmployee, CommandType.Defend);
            }
            // S - 驻守
            else if (Input.GetKeyDown(KeyCode.S))
            {
                IssueCommand(SelectedEmployee, CommandType.Hold);
            }
            // R - 撤退
            else if (Input.GetKeyDown(KeyCode.R))
            {
                IssueCommand(SelectedEmployee, CommandType.Retreat);
            }
            // Tab - 切换选中
            else if (Input.GetKeyDown(KeyCode.Tab))
            {
                SelectNextEmployee();
            }
        }
        
        /// <summary>
        /// 处理玩家移动
        /// </summary>
        private void ProcessPlayerMovement()
        {
            if (_rigidbody == null) return;
            
            _rigidbody.velocity = _moveInput * _stats.MoveSpeed;
            
            // 翻转精灵
            if (_spriteRenderer != null && _moveInput.x != 0)
            {
                _spriteRenderer.flipX = _moveInput.x < 0;
            }
            
            // 切换到移动状态
            if (CurrentState != UnitState.Move)
            {
                ChangeState(UnitState.Move);
            }
        }
        
        // ==================== 员工选中 ====================
        
        /// <summary>
        /// 尝试选中员工
        /// </summary>
        private void TrySelectEmployee()
        {
            // 获取鼠标位置
            Vector3 mousePos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
            mousePos.z = 0;
            
            // 检测点击的对象
            Collider2D hit = Physics2D.OverlapPoint(mousePos);
            if (hit != null)
            {
                Employee employee = hit.GetComponent<Employee>();
                if (employee != null && IsInCommandRange(employee))
                {
                    SelectEmployee(employee);
                    return;
                }
            }
            
            // 点击空白处取消选中
            DeselectEmployee();
        }
        
        /// <summary>
        /// 选中员工
        /// </summary>
        public void SelectEmployee(Employee employee)
        {
            // 取消之前的选中
            if (SelectedEmployee != null)
            {
                SelectedEmployee.SetSelected(false);
            }
            
            SelectedEmployee = employee;
            SelectedEmployee.SetSelected(true);
            
            CYLog.Info($"[老板] 选中员工: {employee.Config?.unitName}");
        }
        
        /// <summary>
        /// 取消选中
        /// </summary>
        public void DeselectEmployee()
        {
            if (SelectedEmployee != null)
            {
                SelectedEmployee.SetSelected(false);
                SelectedEmployee = null;
            }
        }
        
        /// <summary>
        /// 选中下一个员工
        /// </summary>
        private void SelectNextEmployee()
        {
            if (_employeesInRange.Count == 0) return;
            
            int currentIndex = SelectedEmployee != null 
                ? _employeesInRange.IndexOf(SelectedEmployee) 
                : -1;
            
            int nextIndex = (currentIndex + 1) % _employeesInRange.Count;
            SelectEmployee(_employeesInRange[nextIndex]);
        }
        
        // ==================== 指挥范围 ====================
        
        /// <summary>
        /// 更新范围内的员工列表
        /// </summary>
        private void UpdateEmployeesInRange()
        {
            _employeesInRange.Clear();
            
            // 查找所有员工
            var allEmployees = FindObjectsOfType<Employee>();
            foreach (var employee in allEmployees)
            {
                if (employee.IsAlive && IsInCommandRange(employee))
                {
                    _employeesInRange.Add(employee);
                    employee.SetInCommandRange(true);
                }
                else
                {
                    employee.SetInCommandRange(false);
                }
            }
            
            // 如果选中的员工离开范围，取消选中
            if (SelectedEmployee != null && !IsInCommandRange(SelectedEmployee))
            {
                CYLog.Info($"[老板] {SelectedEmployee.Config?.unitName} 离开指挥范围，取消选中");
                DeselectEmployee();
            }
        }
        
        /// <summary>
        /// 检查单位是否在指挥范围内
        /// </summary>
        public bool IsInCommandRange(Unit unit)
        {
            if (unit == null) return false;
            return GetDistanceTo(unit) <= _commandRange;
        }
        
        /// <summary>
        /// 更新指挥范围可视化
        /// </summary>
        private void UpdateCommandRangeVisual()
        {
            if (_commandRangeIndicator != null)
            {
                // 缩放圆形指示器
                float scale = _commandRange * 2f;
                _commandRangeIndicator.transform.localScale = new Vector3(scale, scale, 1f);
            }
        }
        
        /// <summary>
        /// 设置指挥范围（装备升级用）
        /// </summary>
        public void SetCommandRange(float range)
        {
            _commandRange = Mathf.Max(_baseCommandRange, range);
            UpdateCommandRangeVisual();
            CYLog.Info($"[老板] 指挥范围更新为: {_commandRange}米");
        }
        
        // ==================== 下达指令 ====================
        
        /// <summary>
        /// 下达移动指令
        /// </summary>
        private void IssueMovementCommand()
        {
            Vector3 targetPos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
            targetPos.z = 0;
            
            IssueCommand(SelectedEmployee, CommandType.AttackMove, targetPos);
        }
        
        /// <summary>
        /// 向员工下达指令
        /// </summary>
        public void IssueCommand(Employee employee, CommandType command, Vector3? targetPosition = null)
        {
            if (employee == null) return;
            
            // 检查是否在指挥范围内
            if (!IsInCommandRange(employee))
            {
                CYLog.Warning($"[老板] {employee.Config?.unitName} 不在指挥范围内，无法下达指令");
                return;
            }
            
            // 下达指令
            switch (command)
            {
                case CommandType.Follow:
                    employee.SetFollowTarget(this);
                    CYLog.Info($"[老板] 命令 {employee.Config?.unitName} 跟随");
                    break;
                    
                case CommandType.AttackMove:
                    if (targetPosition.HasValue)
                    {
                        employee.SetAttackMoveTarget(targetPosition.Value);
                        CYLog.Info($"[老板] 命令 {employee.Config?.unitName} 攻击移动到 {targetPosition.Value}");
                    }
                    break;
                    
                case CommandType.Defend:
                    employee.SetDefendMode();
                    CYLog.Info($"[老板] 命令 {employee.Config?.unitName} 防御");
                    break;
                    
                case CommandType.Hold:
                    employee.SetHoldPosition();
                    CYLog.Info($"[老板] 命令 {employee.Config?.unitName} 驻守");
                    break;
                    
                case CommandType.Retreat:
                    employee.Retreat();
                    CYLog.Info($"[老板] 命令 {employee.Config?.unitName} 撤退");
                    break;
            }
        }
        
        /// <summary>
        /// 向所有范围内员工下达指令
        /// </summary>
        public void IssueCommandToAll(CommandType command)
        {
            foreach (var employee in _employeesInRange)
            {
                IssueCommand(employee, command);
            }
        }
        
        // ==================== 死亡与复活 ====================
        
        public override void Die(Unit killer = null)
        {
            if (CurrentState == UnitState.Dead) return;
            
            ChangeState(UnitState.Dead);
            _respawnTimer = _respawnTime;
            
            // 计算惩罚
            int goldLoss = Mathf.RoundToInt(GameManager.Instance.Gold * _goldLossPercent);
            
            // 发布事件
            var evt = new BossDiedEvent { GoldLost = goldLoss };
            _eventBus.Post(ref evt);
            
            // 扣除资金
            GameManager.Instance.SpendGold(goldLoss);
            
            CYLog.Warning($"[老板] 倒下了！损失 {goldLoss} 资金，{_respawnTime} 秒后复活");
        }
        
        /// <summary>
        /// 复活
        /// </summary>
        private void Respawn()
        {
            _stats.FullHeal();
            ChangeState(UnitState.Idle);
            
            CYLog.Info("[老板] 复活了！");
        }
        
        // ==================== Gizmos ====================
        
        #if UNITY_EDITOR
        protected override void OnDrawGizmosSelected()
        {
            base.OnDrawGizmosSelected();
            
            // 绘制指挥范围
            Gizmos.color = Color.cyan;
            Gizmos.DrawWireSphere(transform.position, _commandRange);
        }
        #endif
    }
}
```

## 📝 第二步：创建指挥范围指示器

### 2.1 创建指示器精灵

1. 在场景中右键 > `2D Object > Sprites > Circle`
2. 重命名为 `CommandRangeIndicator`
3. 设置：
   - Color: 青色半透明 (0, 1, 1, 0.2)
   - Order in Layer: -1（在角色下面）

### 2.2 作为子对象

1. 把 `CommandRangeIndicator` 拖到老板对象下作为子对象
2. Position 设为 (0, 0, 0)

## 📝 第三步：创建老板预制体

### 3.1 创建老板对象

1. 在场景中右键 > `2D Object > Sprites > Square`
2. 重命名为 `Boss`
3. 设置颜色为深灰色
4. 添加组件：
   - `Box Collider 2D`
   - `Rigidbody 2D`（Gravity Scale = 0，Freeze Rotation Z）
   - `Boss` 脚本

### 3.2 添加子对象

1. 创建 `CommandRangeIndicator`（如上一步）
2. 拖到 `Boss` 下作为子对象
3. 在 Boss 脚本的 `Command Range Indicator` 字段拖入这个子对象

### 3.3 保存为预制体

1. 把 `Boss` 拖到 `Assets/_Game/Prefabs/Units`
2. 命名为 `Boss`

## 📝 第四步：测试老板控制

### 4.1 创建测试场景

### 4.2 添加相机跟随（可选）

创建简单的相机跟随脚本：

1. 右键 `Assets/_Game/Scripts/Core`
2. `Create > C# Script`
3. 命名为 `CameraFollow`

```csharp
using UnityEngine;

namespace LiangXin
{
    /// <summary>
    /// 简单的相机跟随
    /// </summary>
    public class CameraFollow : MonoBehaviour
    {
        [SerializeField] private Transform _target;
        [SerializeField] private float _smoothSpeed = 5f;
        [SerializeField] private Vector3 _offset = new Vector3(0, 0, -10);
        
        void LateUpdate()
        {
            if (_target == null) return;
            
            Vector3 targetPos = _target.position + _offset;
            transform.position = Vector3.Lerp(transform.position, targetPos, _smoothSpeed * Time.deltaTime);
        }
        
        public void SetTarget(Transform target)
        {
            _target = target;
        }
    }
}
```

4. 把这个脚本挂到 Main Camera 上
5. 把 Boss 对象拖到 Target 字段
