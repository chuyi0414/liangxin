# 02_数据配置系统

## 目标
将策划文档转为 ScriptableObject，战斗/指挥/Roguelike/Meta 全部数据化，运行时通过 CY.Resource 读取。

## 数据资产类型（建议）
- `UnitDefinition`：职业、基础属性（HP/攻速/移速/射程/伤害）、AI 等级能力、特殊被动、掉落、Prefab 引用。
- `DepartmentDefinition`：部门枚举、部门 Buff（加成%、阈值）、权重。
- `CommandDefinition`：指令类型（Follow/AttackMove/Defend/Hold/Retreat/Rally）、范围、持续、冷却等。
- `WaveDefinition`：波次列表、出怪时间线、敌人组合、方向提示、流量刺开关。
- `EncounterDefinition`：事件条件、选项（描述/消耗/奖励）、触发时机。
- `ArtifactDefinition`：办公用品/遗物，稀有度、效果脚本 Id、叠加规则。
- `MetaUpgradeDefinition`：装修/声望升级，每级效果、消耗。

## 路径与加载
- 放置：`Assets/_Game/ScriptableObjects/**`，按类别分子目录。
- 加载：使用 `CY.Resource.Load<T>("path")` 或批量加载；高频数据可在 Bootstrap 预加载缓存。
- 运行中切换：避免在 Update 中反复 Load；用字典缓存。

## 字段建议（示例）
```csharp
public class UnitDefinition : ScriptableObject
{
    public string Id;
    public string DisplayName;
    public DepartmentType Department;
    public int Level;           // Lv1-Lv5
    public float Hp;
    public float Attack;
    public float AttackSpeed;
    public float MoveSpeed;
    public float Range;
    public string PassiveId;    // 映射到被动实现
    public GameObject Prefab;
    public int DropGold;
    public int DropCorruption;
}
```

## 策划映射
- `友方单位库/敌方单位库` → UnitDefinition & WaveDefinition。
- `词条系统库` → ArtifactDefinition/被动脚本 Id。
- `游戏内容扩展库` → 事件/扩展单位/特殊波次。
- `核心策划案` → 指令参数、Boss 自闭/复活规则、资源定义。

## 校验与版本
- 统一 Id：各表使用唯一字符串 Id，避免硬编码。
- 数值变更：改表后跑冒烟，确认战斗/掉落/事件一致。
- 版本管理：SO 变更注意合并冲突，必要时提供导出 JSON 方便比对。

## 自测
- 资源加载无 Missing/Null，波次可生成敌人，指令/被动生效。
- 事件表选项与策划描述一致，奖励/代价正确。
- Meta 升级存档正确读写。
