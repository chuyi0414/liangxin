# 01. 游戏启动流程

> 本章教你：创建 GameManager，管理游戏状态（菜单、战斗、结算）

---

## 🎯 本章目标

1. 理解游戏状态机的概念
2. 创建 GameManager 管理游戏流程
3. 定义游戏事件

完成后，你的游戏能够：
- 启动时显示"准备开始"
- 按空格开始战斗
- 战斗结束后显示结算

---

## 📖 概念讲解：游戏状态机

游戏有多个"状态"，每个状态有不同的行为：

```
┌──────────────────────────────────────────────────────┐
│                     游戏状态机                         │
├──────────────────────────────────────────────────────┤
│                                                      │
│   ┌─────────┐     开始      ┌─────────┐             │
│   │  菜单   │ ──────────→   │  战斗   │             │
│   │  Menu   │               │ Battle  │             │
│   └─────────┘               └────┬────┘             │
│                                  │                  │
│                              胜利/失败               │
│                                  │                  │
│                                  ▼                  │
│                            ┌─────────┐              │
│                            │  结算   │              │
│                            │ Result  │              │
│                            └────┬────┘              │
│                                  │                  │
│                               返回                   │
│                                  │                  │
│                                  ▼                  │
│                            回到菜单                  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 📝 第一步：定义游戏事件

### 1.1 创建事件文件

1. 右键 `Assets/_Game/Scripts/Core`
2. `Create > C# Script`
3. 命名为 `GameEvents`

### 1.2 编写事件代码

```csharp
using UnityEngine;

/// <summary>
/// 游戏事件定义
/// 所有事件必须是 struct！
/// </summary>
namespace LiangXin.Events
{
    // ==================== 游戏流程事件 ====================
    
    /// <summary>
    /// 游戏开始事件
    /// </summary>
    public struct GameStartEvent
    {
        public int StageId;  // 关卡 ID
    }
    
    /// <summary>
    /// 游戏暂停事件
    /// </summary>
    public struct GamePauseEvent
    {
        public bool IsPaused;
    }
    
    /// <summary>
    /// 游戏结束事件
    /// </summary>
    public struct GameOverEvent
    {
        public bool IsVictory;   // 是否胜利
        public int WaveReached;  // 坚持到第几波
        public int Score;        // 得分
    }
    
    /// <summary>
    /// 返回主菜单事件
    /// </summary>
    public struct ReturnToMenuEvent { }
    
    // ==================== 波次事件 ====================
    
    /// <summary>
    /// 波次开始事件
    /// </summary>
    public struct WaveStartEvent
    {
        public int WaveNumber;      // 第几波
        public float PrepareTime;   // 准备时间
    }
    
    /// <summary>
    /// 波次结束事件
    /// </summary>
    public struct WaveEndEvent
    {
        public int WaveNumber;
        public int EnemiesKilled;
    }
    
    // ==================== 单位事件 ====================
    
    /// <summary>
    /// 单位生成事件
    /// </summary>
    public struct UnitSpawnedEvent
    {
        public int UnitId;
        public bool IsEnemy;
        public Vector3 Position;
    }
    
    /// <summary>
    /// 单位死亡事件
    /// </summary>
    public struct UnitDiedEvent
    {
        public int UnitId;
        public bool IsEnemy;
        public int KillerId;
        public Vector3 Position;
    }
    
    /// <summary>
    /// 单位升级事件
    /// </summary>
    public struct UnitLevelUpEvent
    {
        public int UnitId;
        public int OldLevel;
        public int NewLevel;
    }
    
    // ==================== 资源事件 ====================
    
    /// <summary>
    /// 资金变化事件
    /// </summary>
    public struct GoldChangedEvent
    {
        public int OldAmount;
        public int NewAmount;
        public int Delta;
    }
    
    /// <summary>
    /// 良心值变化事件
    /// </summary>
    public struct ConscienceChangedEvent
    {
        public int OldAmount;
        public int NewAmount;
        public int Delta;
    }
    
    // ==================== 老板事件 ====================
    
    /// <summary>
    /// 老板受伤事件
    /// </summary>
    public struct BossDamagedEvent
    {
        public int Damage;
        public int CurrentHP;
        public int MaxHP;
    }
    
    /// <summary>
    /// 老板死亡事件
    /// </summary>
    public struct BossDiedEvent
    {
        public int GoldLost;  // 损失的资金
    }
}
```

## 📝 第二步：定义游戏状态枚举

### 2.1 创建状态枚举文件

1. 右键 `Assets/_Game/Scripts/Core`
2. `Create > C# Script`
3. 命名为 `GameEnums`

### 2.2 编写枚举代码

```csharp
/// <summary>
/// 游戏相关枚举定义
/// </summary>
namespace LiangXin
{
    /// <summary>
    /// 游戏状态
    /// </summary>
    public enum GameState
    {
        None,       // 未初始化
        Menu,       // 主菜单
        Loading,    // 加载中
        Prepare,    // 波次准备
        Battle,     // 战斗中
        Paused,     // 暂停
        Victory,    // 胜利
        Defeat      // 失败
    }
    
    /// <summary>
    /// 单位阵营
    /// </summary>
    public enum UnitFaction
    {
        Player,     // 友方（员工）
        Enemy       // 敌方
    }
    
    /// <summary>
    /// 员工等级
    /// </summary>
    public enum EmployeeLevel
    {
        Lv1 = 1,    // 正式员工（潜力股）
        Lv2 = 2,    // 资深员工（完全体）
        Lv3 = 3,    // 业务骨干（消除负面词条）
        Lv4 = 4,    // 核心骨干（添加正面词条）
        Lv5 = 5     // 行业传奇（传奇大招）
    }
    
    /// <summary>
    /// 指令类型
    /// </summary>
    public enum CommandType
    {
        None,
        Follow,         // 跟随老板
        AttackMove,     // 攻击移动
        Defend,         // 防御
        Hold,           // 驻守
        Retreat         // 撤退
    }
    
    /// <summary>
    /// UI 层级
    /// </summary>
    public enum UILayerType
    {
        Background = 0,
        Main = 100,
        Popup = 200,
        Tips = 300,
        Loading = 500
    }
}
```

## 📝 第三步：创建 GameManager

### 3.1 创建 GameManager 脚本

1. 右键 `Assets/_Game/Scripts/Core`
2. `Create > C# Script`
3. 命名为 `GameManager`

### 3.2 编写 GameManager 代码

```csharp
using UnityEngine;
using CYFramework.Infrastructure;
using CYFramework.Core.Event;
using LiangXin.Events;

namespace LiangXin
{
    /// <summary>
    /// 游戏管理器
    /// 管理游戏的整体流程和状态
    /// </summary>
    public class GameManager : MonoBehaviour
    {
        // ==================== 单例 ====================
        
        public static GameManager Instance { get; private set; }
        
        // ==================== 状态 ====================
        
        /// <summary>
        /// 当前游戏状态
        /// </summary>
        public GameState CurrentState { get; private set; } = GameState.None;
        
        /// <summary>
        /// 上一个状态（用于暂停恢复）
        /// </summary>
        private GameState _previousState;
        
        // ==================== 资源 ====================
        
        /// <summary>
        /// 当前资金
        /// </summary>
        public int Gold { get; private set; } = 100;
        
        /// <summary>
        /// 良心值（0-100）
        /// </summary>
        public int Conscience { get; private set; } = 50;
        
        /// <summary>
        /// 当前波次
        /// </summary>
        public int CurrentWave { get; private set; } = 0;
        
        // ==================== 服务引用 ====================
        
        private EventBus _eventBus;
        
        // ==================== 生命周期 ====================
        
        void Awake()
        {
            // 单例设置
            if (Instance != null && Instance != this)
            {
                Destroy(gameObject);
                return;
            }
            Instance = this;
            DontDestroyOnLoad(gameObject);
        }
        
        void Start()
        {
            // 获取事件总线
            _eventBus = ServiceLocator.Get<EventBus>();
            
            // 订阅事件
            SubscribeEvents();
            
            // 初始化完成，进入菜单状态
            ChangeState(GameState.Menu);
            
            CYLog.Info("[GameManager] 初始化完成");
        }
        
        void Update()
        {
            // 处理输入
            HandleInput();
        }
        
        void OnDestroy()
        {
            // 取消订阅
            _eventBus?.UnsubscribeAll(this);
        }
        
        // ==================== 事件订阅 ====================
        
        /// <summary>
        /// 订阅所有需要监听的事件
        /// </summary>
        private void SubscribeEvents()
        {
            _eventBus.Subscribe<GameOverEvent>(OnGameOver, this);
            _eventBus.Subscribe<ReturnToMenuEvent>(OnReturnToMenu, this);
            _eventBus.Subscribe<WaveEndEvent>(OnWaveEnd, this);
        }
        
        // ==================== 输入处理 ====================
        
        /// <summary>
        /// 处理输入
        /// </summary>
        private void HandleInput()
        {
            // 空格键：开始游戏
            if (Input.GetKeyDown(KeyCode.Space))
            {
                if (CurrentState == GameState.Menu)
                {
                    StartGame();
                }
                else if (CurrentState == GameState.Prepare)
                {
                    // 跳过准备时间，直接开始战斗
                    ChangeState(GameState.Battle);
                }
            }
            
            // ESC 键：暂停/恢复
            if (Input.GetKeyDown(KeyCode.Escape))
            {
                if (CurrentState == GameState.Battle || CurrentState == GameState.Prepare)
                {
                    PauseGame();
                }
                else if (CurrentState == GameState.Paused)
                {
                    ResumeGame();
                }
            }
            
            // 测试用：按 V 键胜利，按 D 键失败
            #if UNITY_EDITOR
            if (Input.GetKeyDown(KeyCode.V) && CurrentState == GameState.Battle)
            {
                EndGame(true);
            }
            if (Input.GetKeyDown(KeyCode.D) && CurrentState == GameState.Battle)
            {
                EndGame(false);
            }
            #endif
        }
        
        // ==================== 状态管理 ====================
        
        /// <summary>
        /// 切换游戏状态
        /// </summary>
        public void ChangeState(GameState newState)
        {
            if (CurrentState == newState) return;
            
            var oldState = CurrentState;
            CurrentState = newState;
            
            CYLog.Info($"[GameManager] 状态切换: {oldState} → {newState}");
            
            // 根据新状态执行相应逻辑
            OnStateEnter(newState);
        }
        
        /// <summary>
        /// 进入新状态时的处理
        /// </summary>
        private void OnStateEnter(GameState state)
        {
            switch (state)
            {
                case GameState.Menu:
                    OnEnterMenu();
                    break;
                case GameState.Prepare:
                    OnEnterPrepare();
                    break;
                case GameState.Battle:
                    OnEnterBattle();
                    break;
                case GameState.Paused:
                    OnEnterPaused();
                    break;
                case GameState.Victory:
                    OnEnterVictory();
                    break;
                case GameState.Defeat:
                    OnEnterDefeat();
                    break;
            }
        }
        
        // ==================== 状态进入处理 ====================
        
        private void OnEnterMenu()
        {
            Time.timeScale = 1f;
            CYLog.Info("========================================");
            CYLog.Info("    《良心防线：公司保卫战》");
            CYLog.Info("    按 [空格] 开始游戏");
            CYLog.Info("========================================");
        }
        
        private void OnEnterPrepare()
        {
            CurrentWave++;
            
            // 发布波次开始事件
            var evt = new WaveStartEvent
            {
                WaveNumber = CurrentWave,
                PrepareTime = 10f
            };
            _eventBus.Post(ref evt);
            
            CYLog.Info($"[波次 {CurrentWave}] 准备阶段，按空格跳过准备时间");
        }
        
        private void OnEnterBattle()
        {
            Time.timeScale = 1f;
            CYLog.Info($"[波次 {CurrentWave}] 战斗开始！");
        }
        
        private void OnEnterPaused()
        {
            Time.timeScale = 0f;
            
            var evt = new GamePauseEvent { IsPaused = true };
            _eventBus.Post(ref evt);
            
            CYLog.Info("[游戏暂停] 按 ESC 继续");
        }
        
        private void OnEnterVictory()
        {
            Time.timeScale = 0f;
            CYLog.Info("========================================");
            CYLog.Info("    🎉 胜利！你成功保卫了公司！");
            CYLog.Info($"    坚持波次: {CurrentWave}");
            CYLog.Info($"    最终资金: {Gold}");
            CYLog.Info("========================================");
        }
        
        private void OnEnterDefeat()
        {
            Time.timeScale = 0f;
            CYLog.Info("========================================");
            CYLog.Info("    💀 失败...公司倒闭了");
            CYLog.Info($"    坚持波次: {CurrentWave}");
            CYLog.Info("========================================");
        }
        
        // ==================== 公开方法 ====================
        
        /// <summary>
        /// 开始游戏
        /// </summary>
        public void StartGame()
        {
            CYLog.Info("[GameManager] 开始游戏");
            
            // 重置数据
            Gold = 100;
            Conscience = 50;
            CurrentWave = 0;
            
            // 进入准备状态
            ChangeState(GameState.Prepare);
            
            // 发布游戏开始事件
            var evt = new GameStartEvent { StageId = 1 };
            _eventBus.Post(ref evt);
        }
        
        /// <summary>
        /// 暂停游戏
        /// </summary>
        public void PauseGame()
        {
            _previousState = CurrentState;
            ChangeState(GameState.Paused);
        }
        
        /// <summary>
        /// 恢复游戏
        /// </summary>
        public void ResumeGame()
        {
            Time.timeScale = 1f;
            ChangeState(_previousState);
            
            var evt = new GamePauseEvent { IsPaused = false };
            _eventBus.Post(ref evt);
            
            CYLog.Info("[游戏继续]");
        }
        
        /// <summary>
        /// 结束游戏
        /// </summary>
        public void EndGame(bool isVictory)
        {
            // 发布游戏结束事件
            var evt = new GameOverEvent
            {
                IsVictory = isVictory,
                WaveReached = CurrentWave,
                Score = Gold + Conscience * 10
            };
            _eventBus.Post(ref evt);
            
            ChangeState(isVictory ? GameState.Victory : GameState.Defeat);
        }
        
        /// <summary>
        /// 返回主菜单
        /// </summary>
        public void ReturnToMenu()
        {
            ChangeState(GameState.Menu);
        }
        
        // ==================== 资源管理 ====================
        
        /// <summary>
        /// 增加资金
        /// </summary>
        public void AddGold(int amount)
        {
            int oldGold = Gold;
            Gold += amount;
            
            var evt = new GoldChangedEvent
            {
                OldAmount = oldGold,
                NewAmount = Gold,
                Delta = amount
            };
            _eventBus.Post(ref evt);
            
            CYLog.Info($"[资金] +{amount}，当前: {Gold}");
        }
        
        /// <summary>
        /// 消耗资金
        /// </summary>
        public bool SpendGold(int amount)
        {
            if (Gold < amount)
            {
                CYLog.Warning($"[资金] 不足！需要 {amount}，当前只有 {Gold}");
                return false;
            }
            
            int oldGold = Gold;
            Gold -= amount;
            
            var evt = new GoldChangedEvent
            {
                OldAmount = oldGold,
                NewAmount = Gold,
                Delta = -amount
            };
            _eventBus.Post(ref evt);
            
            CYLog.Info($"[资金] -{amount}，当前: {Gold}");
            return true;
        }
        
        /// <summary>
        /// 增加良心值
        /// </summary>
        public void AddConscience(int amount)
        {
            int oldValue = Conscience;
            Conscience = Mathf.Clamp(Conscience + amount, 0, 100);
            
            var evt = new ConscienceChangedEvent
            {
                OldAmount = oldValue,
                NewAmount = Conscience,
                Delta = Conscience - oldValue
            };
            _eventBus.Post(ref evt);
        }
        
        // ==================== 事件处理 ====================
        
        private void OnGameOver(ref GameOverEvent evt)
        {
            // 游戏结束的额外处理
        }
        
        private void OnReturnToMenu(ref ReturnToMenuEvent evt)
        {
            ReturnToMenu();
        }
        
        private void OnWaveEnd(ref WaveEndEvent evt)
        {
            CYLog.Info($"[波次 {evt.WaveNumber}] 结束，击杀: {evt.EnemiesKilled}");
            
            // 进入下一波准备阶段
            ChangeState(GameState.Prepare);
        }
    }
}
```

## 📝 第四步：挂载 GameManager

### 4.1 创建 Game 对象

1. 打开 Bootstrap 场景
2. 在 Hierarchy 右键 > `Create Empty`
3. 重命名为 `[Game]`
4. 把 `GameManager` 脚本拖到这个对象上

### 4.2 删除测试脚本

1. 选中 `[CYFramework]` 对象
2. 在 Inspector 中找到 `FrameworkTest` 组件
3. 右键组件标题 > `Remove Component`
