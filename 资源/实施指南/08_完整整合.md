# 08_完整整合

## 目标
将流程、单位、指挥、波次、UI、事件、Meta 全部串起来，形成可循环的可玩版本，并满足发布/平台要求。

## 整合步骤
1) 流程串联  
   - `Bootstrap` 预加载配置/资源 → `Menu`（UI）→ `Battle`（战斗）→ `Result`（结算/返回）。  
   - 改流程后生成注册表，确保 WebGL/微信可用。
2) 数据就绪  
   - 加载 ScriptableObject：单位/部门/指令/波次/事件/遗物/Meta 升级。  
   - 波次/事件表版本与策划一致。
3) 战斗运行  
   - 波次按表刷新敌人；员工招募/升级；Boss 指令可用；资源收支正确。  
   - 随机事件触发，选项生效；流量刺偶发提示。
4) UI/交互  
   - 主界面进入战斗；战斗 HUD 显示资源/指令/波次；事件弹窗与结算界面正常。  
   - UI 关闭入池、层级顺序恢复；MVVM 刷新无泄漏。
5) Meta/存档  
   - 结算写入声望/装修升级；主界面加载存档恢复升级与解锁状态。  
   - 使用 `CY.SaveData/CY.LoadData`，自测多次读写。

## 验收清单
- 功能：能从启动到结算完整跑一局；胜/负分支正常；资源、指令、事件、掉落全部生效。  
- 性能：无明显卡顿/GC 峰值；对象池工作正常（单位/UI）。  
- 平台：WebGL/微信打包能跑；流程注册表存在；无路径错误。  
- 稳定：无 Null/Missing；事件订阅无泄漏；UI 关闭不残留。  
- 体验：提示/音效/动效齐全；波次预警与流量刺提示清晰。

## 版本交付
- 提交前：跑一局全流程自测；确认数据与策划同步；更新实施指南必要备注。  
- 如需额外工具/脚本：放在项目侧（非框架核心），并写明用途与路径。
