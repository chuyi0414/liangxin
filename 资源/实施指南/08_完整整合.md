## 📝 第二步：设置游戏场景

│       └── Enemy Prefab: 设置敌人预制体
│

│   └── CameraFollow 组件
│       └── Target: Boss 对象
│
├── Boss                   # 老板（玩家）
│   ├── Boss 组件
│   ├── Rigidbody2D
│   ├── BoxCollider2D
│   └── CommandRangeIndicator (子对象)
│

│   ├── Employee 组件
│   ├── Rigidbody2D
│   └── BoxCollider2D

└── SpawnPoints (自动生成) # 敌人生成点
    ├── SpawnPoint_0
    ├── SpawnPoint_1
    ├── SpawnPoint_2
    └── SpawnPoint_3

### 2.2 设置各组件

**[CYFramework] 对象**：
- 挂载 `CYBootstrap` 组件
- Log Level: Debug
- Fixed Tick Rate: 30

**[Game] 对象**：
- 挂载 `GameManager` 组件
- 挂载 `SimpleHUD` 组件

**[WaveManager] 对象**：
- 挂载 `WaveManager` 组件
- Enemy Prefab: 拖入 Enemy 预制体
- Base Enemy Count: 5
- Enemies Per Wave: 2
- Wave Interval: 10
- Prepare Time: 5（测试时可设短一点）

**Main Camera**：
- 挂载 `CameraFollow` 组件
- Target: 拖入 Boss 对象
- Smooth Speed: 5
- Offset: (0, 0, -10)

**Boss 对象**：
- 挂载 `Boss` 组件
- Base Command Range: 3
- 创建子对象作为指挥范围指示器

## 📝 第四步：完整游戏测试

### 4.1 测试流程

1. **启动游戏**
   - 点击 Play
   - 应该看到框架初始化日志
   - 应该看到 "按 [空格] 开始游戏"

2. **开始游戏**
   - 按空格
   - 应该进入准备阶段
   - 显示波次信息

3. **战斗阶段**
   - 再按空格或等待
   - 敌人开始生成
   - 员工自动攻击敌人

4. **控制老板**
   - WASD 移动老板
   - 观察指挥范围跟随移动

5. **指挥员工**
   - 点击员工选中
   - 按 F 让员工跟随
   - 右键点击地面让员工移动

6. **波次循环**
   - 消灭所有敌人
   - 自动进入下一波

7. **测试胜利/失败**
   - 按 V 键测试胜利
   - 按 D 键测试失败

### 4.2 常见问题排查

**问题：敌人不生成**
- 检查 WaveManager 的 Enemy Prefab 是否设置
- 检查 GameManager 是否正常初始化
- 查看控制台是否有错误

**问题：员工不攻击**
- 检查 Employee 的 Search Radius 是否足够大
- 检查敌人是否有 Collider2D
- 检查敌人的 Faction 是否是 Enemy

**问题：相机不跟随**
- 检查 CameraFollow 的 Target 是否设置
- 检查 Boss 对象是否存在

**问题：UI 不显示**
- 检查 SimpleHUD 组件是否挂载
- 检查 Canvas 是否正常创建

### 5.3 添加招募系统

在 GameManager 中添加招募方法：

```csharp
/// <summary>
/// 招募员工
/// </summary>
public void RecruitEmployee(EmployeeConfig config)
{
    if (config == null) return;
    
    // 检查资金
    if (!SpendGold(config.recruitCost))
    {
        CYLog.Warning("资金不足，无法招募");
        return;
    }
    
    // 生成员工
    var employeePrefab = Resources.Load<GameObject>("Prefabs/Employee");
    if (employeePrefab == null) return;
    
    // 在老板附近生成
    var boss = FindObjectOfType<Boss>();
    Vector3 spawnPos = boss != null 
        ? boss.transform.position + Vector3.right * 2 
        : Vector3.zero;
    
    var obj = Instantiate(employeePrefab, spawnPos, Quaternion.identity);
    var employee = obj.GetComponent<Employee>();
    if (employee != null)
    {
        employee.SetEmployeeConfig(config);
    }
    
    CYLog.Info($"招募了 {config.unitName}");
}
```
