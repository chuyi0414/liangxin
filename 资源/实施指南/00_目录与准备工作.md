# 00_目录与准备工作

## 目录结构（目标形态）
- `Assets/_Game/Art`：占位美术与临时资源。
- `Assets/_Game/Prefabs/UI`：UI 预制体（含 Menu/Battle/Result/事件弹窗等）。
- `Assets/_Game/Prefabs/Units`：员工/敌人/Boss 预制体。
- `Assets/_Game/ScriptableObjects`：数据表（单位/部门/指令/波次/事件/遗物/Meta 升级）。
- `Assets/_Game/Scripts`：按模块拆分
  - `Procedure`：Bootstrap/Menu/Battle/Result 流程。
  - `UI`：Menu、BattleHUD、Result、事件弹窗等。
  - `Battle`：波次/生成器/指挥系统/资源系统/事件系统。
  - `Units`：员工/敌人/Boss 逻辑、AI、状态。
- `Assets/CYFramework`：框架层（勿改核心 API）。
- `资源/策划/*`：策划源文档。
- `资源/实施指南/*`：本系列文档 00-08。

## 基础环境
- Unity：按项目版本打开（保持与现有 Library 匹配）。
- 必跑菜单：改流程后执行 `CYFramework/Generate Procedure Registry`。
- 平台限制：WebGL/微信不依赖 AppDomain 扫描；禁多线程 Job。

## 框架必知 API（只用这些）
- 事件：`CY.Event.Post(ref evt)`；订阅 `void OnX(ref T evt)`；销毁时 `UnsubscribeAll(this)`。
- 流程：`CY.Procedure.Start/Change/ChangeProcedure<T>()`；流程类 `[AutoRegisterProcedure("Name", order: n)]`。
- UI：`CY.UI.Open<T>() / Close<T>() / Back()`；高频 HUD 用 Typed MVVM；关闭回收到 `[ObjectPools]/UI` 并恢复 sibling index。
- 实体：`CY.Entity.RegisterEntity/ShowEntity<T>/HideEntity/PauseEntity`。
- 计时器：`CY.Timer.Delay/Loop/NextFrame`。
- 存档：`CY.SaveData<T>() / CY.LoadData<T>() / CY.HasSave() / CY.DeleteSave()`。
- 资源：`CY.Resource` 按 ResourceLoader 配置。
- 日志：`CY.Log/LogInfo/LogWarning/LogError`。

## 启动前检查清单
- 打开工作区：根目录 `liangxin`，确保 `.code-workspace` 指向项目。
- 场景：`Assets/_Game/Scenes/GameScene` 作为主场景，含 `CYFramework` 预制结构（UIRoot、[ObjectPools]、[Managers] 等）。
- 依赖：确保事件/流程/UI/实体服务已在 CYBootstrap 内初始化。
- 文件编码：使用 UTF-8，无 BOM，中文注释。

## 迭代前同步
- 阅读 `00_实施指南.md` 总则。
- 对照 `资源/策划` 最新版本，更新 ScriptableObject 数据。
- 若修改流程/UI 管理器等底层，确认不违规框架 API，保持向后兼容。
