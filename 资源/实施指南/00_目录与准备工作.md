## 🔧 第一步：检查项目准备情况

### 1.1 确认 CYFramework 已正确导入

打开 Unity，在 Project 窗口检查：

```
Assets/
├── CYFramework/           ✅ 必须存在
│   ├── Runtime/
│   ├── Editor/
│   └── Documentation/
└── ...
```

**如果没有 CYFramework 文件夹**：
1. 把 CYFramework 文件夹复制到 Assets 目录下
2. 等待 Unity 编译完成（没有红色错误）

### 1.2 确认启动场景已配置

1. 打开 `File > Build Settings`
2. 检查是否有一个场景在列表中
3. 如果没有，创建一个：
   - `File > New Scene`
   - `File > Save As` 保存为 `Assets/Scenes/Bootstrap.unity`
   - 在 Build Settings 中点 `Add Open Scenes`

### 1.3 确认 CYBootstrap 已挂载

1. 打开 Bootstrap 场景
2. 在 Hierarchy 中检查是否有 `[CYFramework]` 对象
3. 如果没有：
   - 右键 Hierarchy > `Create Empty`
   - 重命名为 `[CYFramework]`
   - 选中它，`Add Component` > 搜索 `CYBootstrap` > 添加

### 1.4 运行测试

点击 Play，你应该看到这样的日志：

```
=== CYFramework 2.2 启动 ===
平台: WindowsEditor
逻辑帧率: 30Hz
=== CYFramework 初始化完成 ===
```

**看到这些，说明框架已经正常工作！**

## 📁 第二步：创建游戏项目结构

在 Assets 文件夹下创建以下结构：

```
Assets/
├── CYFramework/           # 框架（不要动它）
├── _Game/                 # ⬅️ 你的游戏代码全放这里
│   ├── Scenes/            # 场景
│   ├── Scripts/           # 代码
│   │   ├── Core/          # 核心系统
│   │   ├── Unit/          # 单位相关
│   │   ├── Battle/        # 战斗相关
│   │   ├── UI/            # UI 界面
│   │   └── Data/          # 数据定义
│   ├── Prefabs/           # 预制体
│   │   ├── Units/         # 单位预制体
│   │   ├── Projectiles/   # 投射物
│   │   └── Effects/       # 特效
│   ├── Resources/         # 需要动态加载的资源
│   │   ├── UI/
│   │   └── Configs/
│   ├── ScriptableObjects/ # 配置数据
│   │   ├── Units/
│   │   ├── Enemies/
│   │   └── Traits/
│   └── Art/               # 美术资源
│       ├── Sprites/
│       └── Animations/
└── Scenes/
    └── Bootstrap.unity    # 启动场景
```

### 如何创建这些文件夹？

1. 在 Project 窗口，右键 `Assets`
2. 选择 `Create > Folder`
3. 命名为 `_Game`（前面加下划线是为了排在最前面）
4. 右键 `_Game` > `Create > Folder` > 命名为 `Scripts`
5. 重复上述步骤创建所有子文件夹

## 📝 第三步：创建第一个脚本

让我们创建一个测试脚本，确认一切正常：

### 3.1 创建脚本文件

1. 右键 `Assets/_Game/Scripts/Core`
2. 选择 `Create > C# Script`
3. 命名为 `FrameworkTest`

### 3.2 编写代码

双击打开 `FrameworkTest.cs`，把里面的内容全部删掉，粘贴以下代码：

```csharp
using UnityEngine;
using CYFramework.Infrastructure;
using CYFramework.Core.Event;

/// <summary>
/// 框架测试脚本
/// 用于验证 CYFramework 是否正常工作
/// </summary>
public class FrameworkTest : MonoBehaviour
{
    void Start()
    {
        // 测试日志系统
        CYLog.Info("========================================");
        CYLog.Info("《良心防线》框架测试开始");
        CYLog.Info("========================================");
        
        // 测试服务定位器
        TestServiceLocator();
        
        // 测试事件系统
        TestEventBus();
        
        CYLog.Info("========================================");
        CYLog.Info("所有测试通过！框架工作正常！");
        CYLog.Info("========================================");
    }
    
    /// <summary>
    /// 测试服务定位器
    /// </summary>
    void TestServiceLocator()
    {
        CYLog.Info("[测试] 服务定位器...");
        
        // 获取事件总线
        var eventBus = ServiceLocator.Get<EventBus>();
        if (eventBus != null)
        {
            CYLog.Info("  ✓ EventBus 获取成功");
        }
        else
        {
            CYLog.Error("  ✗ EventBus 获取失败！");
        }
    }
    
    /// <summary>
    /// 测试事件系统
    /// </summary>
    void TestEventBus()
    {
        CYLog.Info("[测试] 事件系统...");
        
        var eventBus = ServiceLocator.Get<EventBus>();
        
        // 订阅测试事件
        eventBus.Subscribe<TestEvent>(OnTestEvent, this);
        
        // 发布测试事件
        var evt = new TestEvent { Message = "Hello 良心防线!" };
        eventBus.Post(ref evt);
        
        // 取消订阅
        eventBus.UnsubscribeAll(this);
        
        CYLog.Info("  ✓ 事件系统工作正常");
    }
    
    /// <summary>
    /// 测试事件处理方法
    /// </summary>
    void OnTestEvent(ref TestEvent evt)
    {
        CYLog.Info($"  → 收到事件: {evt.Message}");
    }
}

/// <summary>
/// 测试用事件（必须是 struct）
/// </summary>
public struct TestEvent
{
    public string Message;
}
```

### 3.3 挂载脚本

1. 回到 Unity
2. 在 Hierarchy 中选中 `[CYFramework]` 对象
3. 把 `FrameworkTest` 脚本拖到 Inspector 上（或者点 Add Component 搜索）

### 3.4 运行测试

点击 Play，你应该看到：

```
========================================
《良心防线》框架测试开始
========================================
[测试] 服务定位器...
  ✓ EventBus 获取成功
[测试] 事件系统...
  → 收到事件: Hello 良心防线!
  ✓ 事件系统工作正常
========================================
所有测试通过！框架工作正常！
========================================
```
