# 01. 游戏启动流程 (v2.0)

> 本章教你：使用 CYFramework 的 Procedure 系统管理游戏流程

---

## 🎯 本章目标

1. 理解 Procedure（流程）系统
2. 创建 GameEntry 管理游戏初始化
3. 使用 CY 统一入口

完成后，你的游戏能够：
- 使用流程系统管理状态（菜单、战斗、结算）
- 通过 CY.Event 发布/订阅事件
- 通过 CY.Timer 管理计时器

---

## 📖 概念讲解：Procedure 流程系统

**为什么用 Procedure 而不是 GameManager？**

| 传统 GameManager | CY.Procedure |
|-----------------|--------------|
| 状态切换用 switch | 每个状态是独立类 |
| 代码集中在一个文件 | 代码分散，易维护 |
| 容易变得臃肿 | 单一职责，清晰 |

```
┌─────────────────────────────────────────────────────────────┐
│                     Procedure 流程系统                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌──────────────┐     开始      ┌──────────────┐          │
│   │MenuProcedure │ ──────────→   │PrepareProcedure│         │
│   └──────────────┘               └───────┬───────┘          │
│                                          │                  │
│                                     准备完成                 │
│                                          │                  │
│                                          ▼                  │
│                                  ┌──────────────┐           │
│                                  │BattleProcedure│          │
│                                  └───────┬───────┘          │
│                                          │                  │
│                           ┌──────────────┴──────────────┐   │
│                           ▼                              ▼  │
│                   ┌──────────────┐              ┌──────────────┐
│                   │VictoryProcedure│            │DefeatProcedure│
│                   └──────────────┘              └──────────────┘
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

namespace LiangXin

## 📝 第二步：创建资源管理器

### 2.1 创建 GameResourceManager.cs

```csharp
// Assets/_Game/Scripts/Core/GameResourceManager.cs
using CYFramework;
using CYFramework.Core.Event;

namespace LiangXin
{
    /// <summary>
    /// 游戏资源管理（金币、良心值、波次）
    /// </summary>
    public class GameResourceManager
    {
        private readonly EventBus _eventBus;
        
        public int Gold { get; private set; } = 100;
        public int Conscience { get; private set; } = 50;
        public int CurrentWave { get; private set; } = 0;
        
        public GameResourceManager(EventBus eventBus)
        {
            _eventBus = eventBus;
        }
        
        public void AddGold(int amount)
        {
            int oldAmount = Gold;
            Gold += amount;
            
            var evt = new GoldChangedEvent
            {
                OldAmount = oldAmount,
                NewAmount = Gold,
                Delta = amount
            };
            _eventBus.Post(ref evt);
        }
        
        public bool SpendGold(int amount)
        {
            if (Gold < amount) return false;
            AddGold(-amount);
            return true;
        }
        
        public void NextWave()
        {
            CurrentWave++;
        }
        
        public void Reset()
        {
            Gold = 100;
            Conscience = 50;
            CurrentWave = 0;
        }
    }
}
```

## 📝 第三步：创建游戏入口

框架提供了 `GameEntryBase` 基类，你只需继承并实现几个方法。

### 方式一：极简模式（推荐）

使用特性自动注册流程 + 自动订阅事件，**代码最少**：

```csharp
// Assets/_Game/Scripts/Core/LiangXinGame.cs
using CYFramework;
using CYFramework.Core;
using CYFramework.Core.Event;
using CYFramework.Infrastructure;

namespace LiangXin
{
    public class LiangXinGame : GameEntryBase
    {
        // 开启自动注册流程（扫描 [AutoRegisterProcedure] 特性）
        protected override bool AutoRegisterProcedures => true;
        
        // 子系统
        public GameResourceManager Resources { get; private set; }
        
        // 便捷访问
        public static LiangXinGame Game => Get<LiangXinGame>();
        public static int Gold => Game?.Resources?.Gold ?? 0;
        
        protected override void OnGameInit()
        {
            Resources = new GameResourceManager(EventBus);
        }
        
        protected override void OnGameStart()
        {
            // 按名称启动流程（不用写泛型）
            CY.Procedure.Start("Menu");
        }
        
        // 加 [OnEvent] 自动订阅，不用手动 Subscribe！
        [OnEvent]
        private void OnGameOver(ref GameOverEvent evt)
        {
            CYLog.Info($"游戏结束: {(evt.IsVictory ? "胜利" : "失败")}");
        }
    }
}
```

流程类只需加个特性就自动注册：

```csharp
[AutoRegisterProcedure("Menu", order: 0)]  // 名称 + 顺序
public class MenuProcedure : ProcedureBase { ... }

[AutoRegisterProcedure("Prepare", order: 1)]
public class PrepareProcedure : ProcedureBase { ... }

[AutoRegisterProcedure("Battle", order: 2)]
public class BattleProcedure : ProcedureBase { ... }
```

切换流程用字符串：

```csharp
// UI 按钮直接调用
CY.Procedure.Change("Battle");

// 或者用泛型
CY.Procedure.Change<BattleProcedure>();
```

---

### 方式二：手动模式

如果你想手动控制注册，可以不开启自动模式：

```csharp
public class LiangXinGame : GameEntryBase
{
    // 默认 false，不自动注册
    // protected override bool AutoRegisterProcedures => false;
    
    public GameResourceManager Resources { get; private set; }
    
    public static LiangXinGame Game => Get<LiangXinGame>();
    
    protected override void OnGameInit()
    {
        Resources = new GameResourceManager(EventBus);
    }
    
    // 手动注册流程
    protected override void RegisterProcedures()
    {
        CY.Procedure.Add<MenuProcedure>("Menu");
        CY.Procedure.Add<PrepareProcedure>("Prepare");
        CY.Procedure.Add<BattleProcedure>("Battle");
    }
    
    protected override void OnGameStart()
    {
        CY.Procedure.Start("Menu");
    }
    
    // [OnEvent] 还是自动订阅的（AutoSubscribeEvents 默认 true）
    [OnEvent]
    private void OnGameOver(ref GameOverEvent evt)
    {
        CYLog.Info($"游戏结束");
    }
}
```

## 📝 第四步：创建流程类

### 4.1 MenuProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/MenuProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using UnityEngine;

namespace LiangXin.Procedures
{
    public class MenuProcedure : ProcedureBase
    {
        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            CYLog.Info("========================================");
            CYLog.Info("    《良心防线：公司保卫战》");
            CYLog.Info("    按 [空格] 开始游戏");
            CYLog.Info("========================================");
        }
        
        protected override void OnUpdate(float deltaTime)
        {
            if (Input.GetKeyDown(KeyCode.Space))
            {
                GameEntry.Instance.StartGame();
            }
        }
    }
}
```

### 4.2 PrepareProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/PrepareProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using UnityEngine;

namespace LiangXin.Procedures
{
    public class PrepareProcedure : ProcedureBase
    {
        private float _prepareTime = 10f;
        private float _elapsed;
        
        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            _elapsed = 0f;
            LiangXinGame.Game.Resources.NextWave();
            
            CYLog.Info($"[波次 {LiangXinGame.CurrentWave}] 准备阶段，按空格跳过");
            
            var evt = new WaveStartEvent 
            { 
                WaveNumber = LiangXinGame.CurrentWave, 
                PrepareTime = _prepareTime 
            };
            CY.Event.Fire(ref evt);
        }
        
        protected override void OnUpdate(float deltaTime)
        {
            _elapsed += deltaTime;
            
            if (Input.GetKeyDown(KeyCode.Space) || _elapsed >= _prepareTime)
            {
                ChangeProcedure<BattleProcedure>();
            }
            
            if (Input.GetKeyDown(KeyCode.Escape))
            {
                ChangeProcedure<PauseProcedure>();
            }
        }
    }
}
```

### 4.3 BattleProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/BattleProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using UnityEngine;

namespace LiangXin.Procedures
{
    public class BattleProcedure : ProcedureBase
    {
        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            Time.timeScale = 1f;
            CYLog.Info($"[波次 {LiangXinGame.CurrentWave}] 战斗开始！");
        }
        
        protected override void OnUpdate(float deltaTime)
        {
            if (Input.GetKeyDown(KeyCode.Escape))
            {
                ChangeProcedure<PauseProcedure>();
                return;
            }
            
            #if UNITY_EDITOR
            if (Input.GetKeyDown(KeyCode.V))
            {
                ChangeProcedure<VictoryProcedure>();
            }
            if (Input.GetKeyDown(KeyCode.D))
            {
                ChangeProcedure<DefeatProcedure>();
            }
            #endif
        }
    }
}
```

## 📝 第五步：场景设置

### 5.1 创建游戏入口对象

1. 在 Hierarchy 中创建空对象，命名为 `[LiangXinGame]`
2. 添加 `LiangXinGame` 组件
3. 确保场景中已有 `[CYBootstrap]` 对象

### 5.2 场景层级结构

```
Hierarchy:
├── [CYBootstrap]      ← 框架启动器（必须）
├── [LiangXinGame]     ← 游戏入口（继承 GameEntryBase）
├── Main Camera
├── Directional Light
└── ...
```

## 🎮 测试游戏

1. 运行游戏
2. 看到 "按空格开始游戏" 日志
3. 按空格 → 进入准备阶段
4. 按空格或等待 10 秒 → 进入战斗
5. 按 ESC → 暂停
6. 按 V → 胜利（编辑器模式）
7. 按 D → 失败（编辑器模式）
