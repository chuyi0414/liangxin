# 01. 游戏启动流程 (v2.0)

> 本章教你：使用 CYFramework 的 Procedure 系统管理游戏流程

---

## 🎯 本章目标

1. 理解 Procedure（流程）系统
2. 创建 GameEntry 管理游戏初始化
3. 使用 CY 统一入口

完成后，你的游戏能够：
- 使用流程系统管理状态（菜单、战斗、结算）
- 通过 CY.Event 发布/订阅事件
- 通过 CY.Timer 管理计时器

## 📖 概念讲解：Procedure 流程系统

**为什么用 Procedure 而不是 GameManager？**

| 传统 GameManager | CY.Procedure |
|-----------------|--------------|
| 状态切换用 switch | 每个状态是独立类 |
| 代码集中在一个文件 | 代码分散，易维护 |
| 容易变得臃肿 | 单一职责，清晰 |

```
┌─────────────────────────────────────────────────────────────┐
│                     Procedure 流程系统                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌──────────────┐     开始      ┌──────────────┐          │
│   │MenuProcedure │ ──────────→   │PrepareProcedure│         │
│   └──────────────┘               └───────┬───────┘          │
│                                          │                  │
│                                     准备完成                 │
│                                          │                  │
│                                          ▼                  │
│                                  ┌──────────────┐           │
│                                  │BattleProcedure│          │
│                                  └───────┬───────┘          │
│                                          │                  │
│                           ┌──────────────┴──────────────┐   │
│                           ▼                              ▼  │
│                   ┌──────────────┐              ┌──────────────┐
│                   │VictoryProcedure│            │DefeatProcedure│
│                   └──────────────┘              └──────────────┘
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 📝 第二步：创建资源管理器

### 2.1 创建 GameResourceManager.cs

```csharp
// Assets/_Game/Scripts/Core/GameResourceManager.cs
using CYFramework;
using CYFramework.Core.Event;

namespace LiangXin
{
    /// <summary>
    /// 游戏资源管理（金币、良心值、波次）
    /// </summary>
    public class GameResourceManager
    {
        private readonly EventBus _eventBus;
        
        public int Gold { get; private set; } = 100;
        public int Conscience { get; private set; } = 50;
        public int CurrentWave { get; private set; } = 0;
        
        public GameResourceManager(EventBus eventBus)
        {
            _eventBus = eventBus;
        }
        
        public void AddGold(int amount)
        {
            int oldAmount = Gold;
            Gold += amount;
            
            var evt = new GoldChangedEvent
            {
                OldAmount = oldAmount,
                NewAmount = Gold,
                Delta = amount
            };
            _eventBus.Post(ref evt);
        }
        
        public bool SpendGold(int amount)
        {
            if (Gold < amount) return false;
            AddGold(-amount);
            return true;
        }
        
        public void NextWave()
        {
            CurrentWave++;
        }
        
        public void Reset()
        {
            Gold = 100;
            Conscience = 50;
            CurrentWave = 0;
        }
    }
}
```

## 📝 第三步：创建游戏入口

框架提供了 `GameEntryBase` 基类，你只需继承并实现几个方法。

### 方式一：极简模式（推荐）

使用特性自动注册流程 + 自动订阅事件，**代码最少**：

```csharp
// Assets/_Game/Scripts/Core/LiangXinGame.cs
using CYFramework;
using CYFramework.Core;
using CYFramework.Core.Event;
using CYFramework.Infrastructure;

namespace LiangXin
{
    public class LiangXinGame : GameEntryBase
    {
        // 开启自动注册流程（扫描 [AutoRegisterProcedure] 特性）
        protected override bool AutoRegisterProcedures => true;
        
        // 子系统
        public GameResourceManager Resources { get; private set; }
        
        // 便捷访问
        public static LiangXinGame Game => Get<LiangXinGame>();
        public static int Gold => Game?.Resources?.Gold ?? 0;
        
        protected override void OnGameInit()
        {
            Resources = new GameResourceManager(EventBus);
        }
        
        protected override void OnGameStart()
        {
            // 按名称启动流程（不用写泛型）
            CY.Procedure.Start("Menu");
        }
        
        // 加 [OnEvent] 自动订阅，不用手动 Subscribe！
        [OnEvent]
        private void OnGameOver(ref GameOverEvent evt)
        {
            CYLog.Info($"游戏结束: {(evt.IsVictory ? "胜利" : "失败")}");
        }
    }
}
```

流程类只需加个特性就自动注册：

```csharp
[AutoRegisterProcedure("Menu", order: 0)]  // 名称 + 顺序
public class MenuProcedure : ProcedureBase { ... }

[AutoRegisterProcedure("Prepare", order: 1)]
public class PrepareProcedure : ProcedureBase { ... }

[AutoRegisterProcedure("Battle", order: 2)]
public class BattleProcedure : ProcedureBase { ... }
```

切换流程用字符串：

```csharp
// UI 按钮直接调用
CY.Procedure.Change("Battle");

// 或者用泛型
CY.Procedure.Change<BattleProcedure>();
```

---

### 方式二：手动模式

如果你想手动控制注册，可以不开启自动模式：

```csharp
public class LiangXinGame : GameEntryBase
{
    // 默认 false，不自动注册
    // protected override bool AutoRegisterProcedures => false;
    
    public GameResourceManager Resources { get; private set; }
    
    public static LiangXinGame Game => Get<LiangXinGame>();
    
    protected override void OnGameInit()
    {
        Resources = new GameResourceManager(EventBus);
    }
    
    // 手动注册流程
    protected override void RegisterProcedures()
    {
        CY.Procedure.Add<MenuProcedure>("Menu");
        CY.Procedure.Add<PrepareProcedure>("Prepare");
        CY.Procedure.Add<BattleProcedure>("Battle");
    }
    
    protected override void OnGameStart()
    {
        CY.Procedure.Start("Menu");
    }
    
    // [OnEvent] 还是自动订阅的（AutoSubscribeEvents 默认 true）
    [OnEvent]
    private void OnGameOver(ref GameOverEvent evt)
    {
        CYLog.Info($"游戏结束");
    }
}
```

## 📝 第四步：创建流程类

> **简化设计**：只用 3 个核心流程，避免过度拆分
> - **Menu** - 菜单入口
> - **Battle** - 战斗（内部管理准备/战斗/暂停阶段）
> - **GameOver** - 结算（统一处理胜利/失败）

```
Assets/_Game/Scripts/Procedures/
├── MenuProcedure.cs      ← 菜单流程
├── BattleProcedure.cs    ← 战斗流程
└── GameOverProcedure.cs  ← 结算流程
```

### 4.1 MenuProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/MenuProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using UnityEngine;

namespace LiangXin.Procedures
{
    /// <summary>
    /// 菜单流程 - 游戏入口
    /// </summary>
    [AutoRegisterProcedure("Menu", order: 0)]
    public class MenuProcedure : ProcedureBase
    {
        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            CYLog.Info("========================================");
            CYLog.Info("    《良心防线：公司保卫战》");
            CYLog.Info("    按 [空格] 开始游戏");
            CYLog.Info("========================================");
        }

        protected override void OnUpdate(float deltaTime)
        {
            if (Input.GetKeyDown(KeyCode.Space))
            {
                CY.Procedure.Change("Battle");
            }
        }
    }
}
```

### 4.2 BattleProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/BattleProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using LiangXin;
using UnityEngine;

namespace LiangXin.Procedures
{
    /// <summary>
    /// 战斗流程 - 包含准备阶段和战斗阶段
    /// </summary>
    [AutoRegisterProcedure("Battle", order: 1)]
    public class BattleProcedure : ProcedureBase
    {
        // 游戏阶段
        private enum Phase { Prepare, Fighting }
        private Phase _currentPhase;
        
        // 准备阶段配置
        private float _prepareTime = 5f;
        private float _elapsed;
        
        // 暂停状态
        private bool _isPaused;

        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            _isPaused = false;
            Time.timeScale = 1f;
            EnterPreparePhase();
        }

        protected override void OnUpdate(float deltaTime)
        {
            // 暂停/恢复
            if (Input.GetKeyDown(KeyCode.Escape))
            {
                TogglePause();
                return;
            }

            if (_isPaused) return;

            switch (_currentPhase)
            {
                case Phase.Prepare:
                    UpdatePreparePhase(deltaTime);
                    break;
                case Phase.Fighting:
                    UpdateFightingPhase();
                    break;
            }
        }

        protected override void OnLeave(ProcedureBase nextProcedure)
        {
            Time.timeScale = 1f;
            _isPaused = false;
        }

        #region 准备阶段
        
        private void EnterPreparePhase()
        {
            _currentPhase = Phase.Prepare;
            _elapsed = 0f;
            LiangXinGame.Game.Resources.NextWave();
            
            CYLog.Info($"[波次 {LiangXinGame.CurrentWave}] 准备阶段 ({_prepareTime}秒)，按空格跳过");
            
            var evt = new WaveStartEvent
            {
                WaveNumber = LiangXinGame.CurrentWave,
                PrepareTime = _prepareTime
            };
            CY.Event.Fire(ref evt);
        }

        private void UpdatePreparePhase(float deltaTime)
        {
            _elapsed += deltaTime;
            if (Input.GetKeyDown(KeyCode.Space) || _elapsed >= _prepareTime)
            {
                EnterFightingPhase();
            }
        }
        
        #endregion

        #region 战斗阶段
        
        private void EnterFightingPhase()
        {
            _currentPhase = Phase.Fighting;
            CYLog.Info($"[波次 {LiangXinGame.CurrentWave}] 战斗开始！");
        }

        private void UpdateFightingPhase()
        {
            #if UNITY_EDITOR
            if (Input.GetKeyDown(KeyCode.V))
                CY.Procedure.Change("GameOver", new GameOverParams { IsVictory = true });
            if (Input.GetKeyDown(KeyCode.D))
                CY.Procedure.Change("GameOver", new GameOverParams { IsVictory = false });
            if (Input.GetKeyDown(KeyCode.N))
                EnterPreparePhase(); // 下一波
            #endif
        }
        
        #endregion

        #region 暂停
        
        private void TogglePause()
        {
            _isPaused = !_isPaused;
            Time.timeScale = _isPaused ? 0f : 1f;
            CYLog.Info(_isPaused ? "游戏暂停 - 按 ESC 继续" : "游戏继续");
            
            var evt = new GamePauseEvent { IsPaused = _isPaused };
            CY.Event.Fire(ref evt);
        }
        
        #endregion
    }
}
```

### 4.3 GameOverProcedure.cs

```csharp
// Assets/_Game/Scripts/Procedures/GameOverProcedure.cs
using CYFramework;
using CYFramework.Core.Procedure;
using CYFramework.Infrastructure;
using LiangXin;
using UnityEngine;

namespace LiangXin.Procedures
{
    /// <summary>
    /// 游戏结束参数
    /// </summary>
    public class GameOverParams
    {
        public bool IsVictory;
    }

    /// <summary>
    /// 结算流程 - 统一处理胜利/失败
    /// 继承泛型基类以接收参数
    /// </summary>
    [AutoRegisterProcedure("GameOver", order: 2)]
    public class GameOverProcedure : ProcedureBase<GameOverParams>
    {
        private bool _isVictory;

        protected override void OnEnter(ProcedureBase previousProcedure)
        {
            // UserData 由框架自动注入
            _isVictory = UserData?.IsVictory ?? false;

            Time.timeScale = 0f;
            
            string result = _isVictory ? "胜利" : "失败";
            CYLog.Info($"========================================");
            CYLog.Info($"    游戏结束 - {result}！");
            CYLog.Info($"    到达波次: {LiangXinGame.CurrentWave}");
            CYLog.Info($"    按 [空格] 返回菜单");
            CYLog.Info($"========================================");

            var evt = new GameOverEvent
            {
                IsVictory = _isVictory,
                WaveReached = LiangXinGame.CurrentWave,
                Score = LiangXinGame.Gold
            };
            CY.Event.Fire(ref evt);
        }

        protected override void OnUpdate(float deltaTime)
        {
            if (Input.GetKeyDown(KeyCode.Space))
            {
                LiangXinGame.Game.Resources.Reset();
                CY.Procedure.Change("Menu");
            }
        }

        protected override void OnLeave(ProcedureBase nextProcedure)
        {
            Time.timeScale = 1f;
        }
    }
}
```

## 🎮 测试游戏

1. 运行游戏，看到 "按空格开始游戏" 日志
2. 按 **空格** → 进入战斗（准备阶段 5 秒）
3. 按 **空格** 或等待 → 进入战斗阶段
4. 按 **ESC** → 暂停/恢复
5. 按 **N** → 下一波（编辑器模式）
6. 按 **V** → 胜利（编辑器模式）
7. 按 **D** → 失败（编辑器模式）
8. 结算界面按 **空格** → 返回菜单
