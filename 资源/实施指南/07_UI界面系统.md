# 07_UI界面系统

## 目标
实现从菜单到战斗/结算/事件的全套 UI，使用 CYFramework UI 管理与 Typed MVVM，保持对象池与层级顺序正确。

## 目录与资源
- 脚本：`Assets/_Game/Scripts/UI/...` 按功能分目录（Menu、Battle、Result、Event 等）。
- 预制体：`Assets/_Game/Prefabs/UI/...`，通过 `[UIPrefab("UI/Menu/Main/MainUI")]` 等标注。
- 管理：使用 `CY.UI.Open/Close/Back`；禁止 `Destroy(this)`。

## 必备界面
- 主界面：开始游戏/设置/退出，进入 `BattleProcedure`。  
- 加载/过场：切流程时使用。  
- 战斗 HUD：资源显示（Gold/Corruption/Conscience）、快捷键提示、波次/倒计时、Boss 状态、自闭提示、指令按钮。  
- 结算界面：胜/负结果、奖励、重新开始/返回菜单。  
- 事件弹窗：Roguelike 事件选项，展示奖励/代价。  
- Meta/装修界面（后期）：声望升级、被动展示。

## MVVM 与数据绑定
- 高频刷新：使用 Typed MVVM（`ObservableProperty` + `TypedMVVMPanel<TViewModel>`）。  
- 订阅：面板打开时绑定，关闭时 Dispose；禁止泄漏。  
- 数据源：资源系统、波次控制、Boss 状态、事件结果。

## 对象池与层级
- UIManager 关闭面板回收到 `[ObjectPools]/UI`，复用时恢复 sibling index。  
- 高层级：Popup/Tips/Guide/Loading/System 层按 UIManager 预设容器使用。

## 交互逻辑
- 按钮 -> 事件：UI 触发命令事件（指挥、招募、升级、事件选择）。  
- 输入提示：显示快捷键（F/A/D/S/R/G/QWERT）。  
- 反馈：指令执行结果/资源变动/波次预警通过 HUD 展示。

## 性能与规范
- 禁用 Update 中 LINQ/闭包；使用计时器或 MVVM 驱动。  
- 所有监听在 `OnDestroy/OnClose` 清理。  
- 文案与数值格式：避免频繁字符串拼接，使用 StringBuilder 或预格式化。

## 自测
- 打开/关闭/返回无残留，UIStack 正常。  
- HUD 实时刷新资源/倒计时；指令点击有效。  
- 事件弹窗选项生效并关闭正确；结算界面流程无阻塞。
