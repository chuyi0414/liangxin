# 05. 友方单位系统

> 本章教你：创建员工类，实现 AI 自动战斗、等级系统、接收指令

---

## 🎯 本章目标

1. 创建 Employee 类（员工）
2. 实现员工 AI（自动寻敌、攻击）
3. 实现等级系统（Lv1-Lv5）
4. 实现指令接收（跟随、防御等）

完成后：
- 员工会自动寻找并攻击敌人
- 可以通过老板下达指令
- 可以升级员工提升能力

---

## 📝 第一步：创建 Employee 类

### 1.1 创建 Employee 脚本

1. 右键 `Assets/_Game/Scripts/Unit`
2. `Create > C# Script`
3. 命名为 `Employee`

### 1.2 编写代码

```csharp
using UnityEngine;
using CYFramework.Infrastructure;
using CYFramework.Core.Event;
using LiangXin.Data;
using LiangXin.Events;
using System.Collections.Generic;

namespace LiangXin.Unit
{
    /// <summary>
    /// 员工（友方单位）
    /// </summary>
    public class Employee : Unit
    {
        // ==================== 属性 ====================
        
        public override UnitFaction Faction => UnitFaction.Player;
        
        // ==================== 员工配置 ====================
        
        [Header("员工配置")]
        [SerializeField] private EmployeeConfig _employeeConfig;
        
        /// <summary>
        /// 员工配置
        /// </summary>
        public EmployeeConfig EmployeeConfig => _employeeConfig;
        
        // ==================== 等级系统 ====================
        
        [Header("等级")]
        [SerializeField] private int _level = 1;
        
        /// <summary>
        /// 当前等级
        /// </summary>
        public int Level => _level;
        
        /// <summary>
        /// 是否满级
        /// </summary>
        public bool IsMaxLevel => _level >= 5;
        
        // ==================== 词条系统 ====================
        
        [Header("词条")]
        [SerializeField] private List<string> _traits = new List<string>();
        
        /// <summary>
        /// 当前词条列表
        /// </summary>
        public IReadOnlyList<string> Traits => _traits;
        
        // ==================== 指令系统 ====================
        
        [Header("指令状态")]
        [SerializeField] private CommandType _currentCommand = CommandType.None;
        
        /// <summary>
        /// 当前执行的指令
        /// </summary>
        public CommandType CurrentCommand => _currentCommand;
        
        /// <summary>
        /// 跟随目标
        /// </summary>
        private Unit _followTarget;
        
        /// <summary>
        /// 攻击移动目标点
        /// </summary>
        private Vector3 _attackMoveTarget;
        
        /// <summary>
        /// 是否处于防御模式
        /// </summary>
        private bool _isDefending;
        
        /// <summary>
        /// 是否驻守（不追击）
        /// </summary>
        private bool _isHolding;
        
        // ==================== 选中状态 ====================
        
        [Header("选中状态")]
        [SerializeField] private bool _isSelected;
        [SerializeField] private bool _isInCommandRange;
        
        /// <summary>
        /// 是否被选中
        /// </summary>
        public bool IsSelected => _isSelected;
        
        /// <summary>
        /// 是否在指挥范围内
        /// </summary>
        public bool IsInCommandRange => _isInCommandRange;
        
        // ==================== 选中指示器 ====================
        
        [SerializeField] private GameObject _selectionIndicator;
        [SerializeField] private GameObject _commandRangeIndicator;
        
        // ==================== AI 参数 ====================
        
        [Header("AI 参数")]
        [SerializeField] private float _searchRadius = 10f;
        [SerializeField] private float _searchInterval = 0.5f;
        
        private float _searchTimer;
        
        // ==================== 技能 ====================
        
        [Header("技能")]
        [SerializeField] private float _skillCooldown;
        
        private float _skillTimer;
        
        // ==================== 生命周期 ====================
        
        protected override void Awake()
        {
            base.Awake();
            
            // 隐藏选中指示器
            if (_selectionIndicator != null)
                _selectionIndicator.SetActive(false);
            if (_commandRangeIndicator != null)
                _commandRangeIndicator.SetActive(false);
        }
        
        protected override void Start()
        {
            base.Start();
            
            // 从员工配置初始化
            if (_employeeConfig != null)
            {
                _config = _employeeConfig;
                InitializeFromConfig();
            }
            
            // Lv1 员工随机获得一个负面词条
            if (_level == 1)
            {
                AddRandomNegativeTrait();
            }
        }
        
        protected override void Update()
        {
            base.Update();
            
            if (!IsAlive) return;
            
            // 更新搜索计时器
            _searchTimer -= Time.deltaTime;
            
            // 更新技能冷却
            if (_skillTimer > 0)
            {
                _skillTimer -= Time.deltaTime;
            }
        }
        
        // ==================== 初始化 ====================
        
        /// <summary>
        /// 从配置初始化
        /// </summary>
        private void InitializeFromConfig()
        {
            if (_employeeConfig == null) return;
            
            // 根据等级计算属性
            _stats.MaxHP = _employeeConfig.GetHPAtLevel(_level);
            _stats.CurrentHP = _stats.MaxHP;
            _stats.Attack = _employeeConfig.GetAttackAtLevel(_level);
            
            // 技能冷却
            _skillCooldown = _employeeConfig.lv2SkillCooldown;
        }
        
        /// <summary>
        /// 设置员工配置
        /// </summary>
        public void SetEmployeeConfig(EmployeeConfig config)
        {
            _employeeConfig = config;
            _config = config;
            InitializeFromConfig();
        }
        
        // ==================== AI 状态机 ====================
        
        protected override void UpdateIdle()
        {
            // 根据指令类型决定行为
            switch (_currentCommand)
            {
                case CommandType.Follow:
                    UpdateFollowBehavior();
                    break;
                    
                case CommandType.AttackMove:
                    UpdateAttackMoveBehavior();
                    break;
                    
                case CommandType.Defend:
                    // 防御模式：原地不动，等待敌人
                    break;
                    
                case CommandType.Hold:
                    // 驻守模式：在原地自由攻击
                    SearchAndAttack();
                    break;
                    
                default:
                    // 默认：自由作战
                    SearchAndAttack();
                    break;
            }
        }
        
        protected override void UpdateMove()
        {
            base.UpdateMove();
            
            // 移动过程中检查是否有敌人
            if (_currentCommand == CommandType.AttackMove)
            {
                SearchAndAttack();
            }
        }
        
        protected override void UpdateAttack()
        {
            // 检查目标是否还有效
            if (CurrentTarget == null || !CurrentTarget.IsAlive)
            {
                CurrentTarget = null;
                ChangeState(UnitState.Idle);
                return;
            }
            
            // 检查是否在攻击范围内
            float distance = GetDistanceTo(CurrentTarget);
            if (distance > _stats.AttackRange)
            {
                // 驻守模式不追击
                if (_isHolding)
                {
                    CurrentTarget = null;
                    ChangeState(UnitState.Idle);
                }
                else
                {
                    // 追击目标
                    MoveTo(CurrentTarget.transform.position);
                }
                return;
            }
            
            // 尝试攻击
            TryAttack();
            
            // Lv2+ 尝试释放技能
            if (_level >= 2)
            {
                TryUseSkill();
            }
        }
        
        // ==================== AI 行为 ====================
        
        /// <summary>
        /// 搜索并攻击敌人
        /// </summary>
        private void SearchAndAttack()
        {
            // 已有目标就继续攻击
            if (CurrentTarget != null && CurrentTarget.IsAlive)
            {
                ChangeState(UnitState.Attack);
                return;
            }
            
            // 定时搜索新目标
            if (_searchTimer <= 0)
            {
                _searchTimer = _searchInterval;
                CurrentTarget = FindNearestEnemy();
                
                if (CurrentTarget != null)
                {
                    ChangeState(UnitState.Attack);
                }
            }
        }
        
        /// <summary>
        /// 寻找最近的敌人
        /// </summary>
        private Unit FindNearestEnemy()
        {
            float searchRange = _level >= 3 ? _searchRadius * 1.5f : _searchRadius;
            
            Collider2D[] hits = Physics2D.OverlapCircleAll(transform.position, searchRange);
            
            Unit nearest = null;
            float nearestDist = float.MaxValue;
            
            foreach (var hit in hits)
            {
                Unit unit = hit.GetComponent<Unit>();
                if (unit != null && unit.Faction == UnitFaction.Enemy && unit.IsAlive)
                {
                    float dist = GetDistanceTo(unit);
                    if (dist < nearestDist)
                    {
                        nearestDist = dist;
                        nearest = unit;
                    }
                }
            }
            
            return nearest;
        }
        
        /// <summary>
        /// 跟随行为
        /// </summary>
        private void UpdateFollowBehavior()
        {
            if (_followTarget == null || !_followTarget.IsAlive)
            {
                _currentCommand = CommandType.None;
                return;
            }
            
            float distance = GetDistanceTo(_followTarget);
            
            // 保持一定距离跟随
            if (distance > 2f)
            {
                MoveTo(_followTarget.transform.position);
            }
            else
            {
                StopMove();
                // 跟随时也可以攻击敌人
                SearchAndAttack();
            }
        }
        
        /// <summary>
        /// 攻击移动行为
        /// </summary>
        private void UpdateAttackMoveBehavior()
        {
            // 优先攻击敌人
            if (CurrentTarget != null && CurrentTarget.IsAlive)
            {
                ChangeState(UnitState.Attack);
                return;
            }
            
            // 没有敌人就移动到目标点
            float distance = Vector3.Distance(transform.position, _attackMoveTarget);
            if (distance > 0.5f)
            {
                MoveTo(_attackMoveTarget);
                
                // 移动过程中搜索敌人
                if (_searchTimer <= 0)
                {
                    _searchTimer = _searchInterval;
                    CurrentTarget = FindNearestEnemy();
                }
            }
            else
            {
                // 到达目标点，切换为驻守
                _currentCommand = CommandType.Hold;
                _isHolding = true;
            }
        }
        
        // ==================== 技能系统 ====================
        
        /// <summary>
        /// 尝试使用技能
        /// </summary>
        private void TryUseSkill()
        {
            if (_level < 2) return;
            if (_skillTimer > 0) return;
            if (CurrentTarget == null) return;
            
            // 释放技能
            UseSkill();
            _skillTimer = _skillCooldown;
        }
        
        /// <summary>
        /// 使用技能（子类可重写）
        /// </summary>
        protected virtual void UseSkill()
        {
            // 默认技能：对目标造成额外伤害
            if (CurrentTarget != null)
            {
                int skillDamage = Mathf.RoundToInt(_stats.Attack * 1.5f);
                CurrentTarget.TakeDamage(skillDamage, this);
                
                CYLog.Debug($"[{_employeeConfig?.unitName}] 释放技能，造成 {skillDamage} 伤害");
            }
        }
        
        // ==================== 指令接收 ====================
        
        /// <summary>
        /// 设置跟随目标
        /// </summary>
        public void SetFollowTarget(Unit target)
        {
            _followTarget = target;
            _currentCommand = CommandType.Follow;
            _isDefending = false;
            _isHolding = false;
        }
        
        /// <summary>
        /// 设置攻击移动目标
        /// </summary>
        public void SetAttackMoveTarget(Vector3 position)
        {
            _attackMoveTarget = position;
            _currentCommand = CommandType.AttackMove;
            _isDefending = false;
            _isHolding = false;
            MoveTo(position);
        }
        
        /// <summary>
        /// 设置防御模式
        /// </summary>
        public void SetDefendMode()
        {
            _currentCommand = CommandType.Defend;
            _isDefending = true;
            _isHolding = true;
            StopMove();
            
            // 防御模式减伤 50%
            // 这里简化处理，实际应该用 Buff 系统
        }
        
        /// <summary>
        /// 设置驻守位置
        /// </summary>
        public void SetHoldPosition()
        {
            _currentCommand = CommandType.Hold;
            _isHolding = true;
            _isDefending = false;
            StopMove();
        }
        
        /// <summary>
        /// 撤退
        /// </summary>
        public void Retreat()
        {
            _currentCommand = CommandType.Retreat;
            _isHolding = false;
            _isDefending = false;
            CurrentTarget = null;
            
            // 向基地方向移动（简化：向原点移动）
            MoveTo(Vector3.zero);
        }
        
        /// <summary>
        /// 清除指令
        /// </summary>
        public void ClearCommand()
        {
            _currentCommand = CommandType.None;
            _followTarget = null;
            _isDefending = false;
            _isHolding = false;
        }
        
        // ==================== 选中状态 ====================
        
        /// <summary>
        /// 设置选中状态
        /// </summary>
        public void SetSelected(bool selected)
        {
            _isSelected = selected;
            if (_selectionIndicator != null)
            {
                _selectionIndicator.SetActive(selected);
            }
        }
        
        /// <summary>
        /// 设置是否在指挥范围内
        /// </summary>
        public void SetInCommandRange(bool inRange)
        {
            _isInCommandRange = inRange;
            if (_commandRangeIndicator != null)
            {
                _commandRangeIndicator.SetActive(inRange);
            }
        }
        
        // ==================== 等级系统 ====================
        
        /// <summary>
        /// 升级
        /// </summary>
        public bool LevelUp()
        {
            if (IsMaxLevel)
            {
                CYLog.Warning($"[{_employeeConfig?.unitName}] 已经是最高等级");
                return false;
            }
            
            // 检查资金
            int cost = _employeeConfig?.GetUpgradeCost(_level) ?? 0;
            if (!GameManager.Instance.SpendGold(cost))
            {
                return false;
            }
            
            int oldLevel = _level;
            _level++;
            
            // 重新计算属性
            InitializeFromConfig();
            
            // Lv3 消除负面词条
            if (_level == 3)
            {
                RemoveNegativeTraits();
                AddRandomPositiveTrait();
            }
            // Lv4 添加正面词条
            else if (_level == 4)
            {
                AddRandomPositiveTrait();
            }
            
            // 发布事件
            var evt = new UnitLevelUpEvent
            {
                UnitId = UnitId,
                OldLevel = oldLevel,
                NewLevel = _level
            };
            _eventBus.Post(ref evt);
            
            CYLog.Info($"[{_employeeConfig?.unitName}] 升级！Lv{oldLevel} → Lv{_level}");
            
            return true;
        }
        
        /// <summary>
        /// 获取升级费用
        /// </summary>
        public int GetUpgradeCost()
        {
            return _employeeConfig?.GetUpgradeCost(_level) ?? 0;
        }
        
        // ==================== 词条系统 ====================
        
        /// <summary>
        /// 添加随机负面词条
        /// </summary>
        private void AddRandomNegativeTrait()
        {
            // 简化：添加一个占位符
            _traits.Add("T-N01");
            CYLog.Debug($"[{_employeeConfig?.unitName}] 获得负面词条");
        }
        
        /// <summary>
        /// 添加随机正面词条
        /// </summary>
        private void AddRandomPositiveTrait()
        {
            _traits.Add("T-P01");
            CYLog.Debug($"[{_employeeConfig?.unitName}] 获得正面词条");
        }
        
        /// <summary>
        /// 移除所有负面词条
        /// </summary>
        private void RemoveNegativeTraits()
        {
            _traits.RemoveAll(t => t.StartsWith("T-N"));
            CYLog.Debug($"[{_employeeConfig?.unitName}] 负面词条已清除");
        }
        
        // ==================== 自闭状态（员工专用死亡）====================
        
        public override void Die(Unit killer = null)
        {
            // 员工不会真正死亡，而是进入自闭状态
            if (CurrentState == UnitState.Disabled) return;
            
            ChangeState(UnitState.Disabled);
            CurrentTarget = null;
            _currentCommand = CommandType.None;
            
            CYLog.Info($"[{_employeeConfig?.unitName}] 进入自闭状态，需要治疗或老板安抚");
        }
        
        /// <summary>
        /// 安抚员工（从自闭状态恢复）
        /// </summary>
        public void Comfort()
        {
            if (CurrentState != UnitState.Disabled) return;
            
            // 惩罚：降一级（Lv5 除外）
            if (_level < 5 && _level > 1)
            {
                _level--;
                InitializeFromConfig();
                CYLog.Warning($"[{_employeeConfig?.unitName}] 被安抚，但等级降至 Lv{_level}");
            }
            
            // 恢复部分血量
            _stats.CurrentHP = _stats.MaxHP / 2;
            
            ChangeState(UnitState.Idle);
            
            CYLog.Info($"[{_employeeConfig?.unitName}] 恢复正常");
        }
        
        // ==================== Gizmos ====================
        
        #if UNITY_EDITOR
        protected override void OnDrawGizmosSelected()
        {
            base.OnDrawGizmosSelected();
            
            // 绘制搜索范围
            Gizmos.color = Color.yellow;
            Gizmos.DrawWireSphere(transform.position, _searchRadius);
        }
        #endif
    }
}
```

## 📝 第二步：创建员工预制体

### 2.1 创建员工对象

1. 在场景中右键 > `2D Object > Sprites > Square`
2. 重命名为 `Employee`
3. 设置颜色为黄色
4. Scale 设为 (0.8, 0.8, 1)（比老板小一点）
5. 添加组件：
   - `Box Collider 2D`
   - `Rigidbody 2D`（Gravity Scale = 0，Freeze Rotation Z）
   - `Employee` 脚本

### 2.2 添加选中指示器

1. 在 Employee 下创建子对象 `SelectionIndicator`
2. 用 Circle Sprite，颜色设为绿色半透明
3. 默认隐藏（取消勾选 Active）
4. 拖到 Employee 脚本的 Selection Indicator 字段

### 2.3 保存为预制体

1. 拖到 `Assets/_Game/Prefabs/Units`
2. 命名为 `Employee`

3. 命名为 `Enemy`

```csharp
using UnityEngine;
using LiangXin.Data;

namespace LiangXin.Unit
{
    /// <summary>
    /// 敌人（简化版，下一章完善）
    /// </summary>
    public class Enemy : Unit
    {
        public override UnitFaction Faction => UnitFaction.Enemy;
        
        [Header("敌人配置")]
        [SerializeField] private EnemyConfig _enemyConfig;
        
        protected override void Start()
        {
            base.Start();
            
            if (_enemyConfig != null)
            {
                _config = _enemyConfig;
                _stats.InitFromConfig(_enemyConfig);
            }
        }
        
        protected override void UpdateIdle()
        {
            // 简单 AI：向左移动（朝向基地）
            MoveTo(transform.position + Vector3.left * 10);
        }
        
        public override void Die(Unit killer = null)
        {
            // 掉落资金
            if (_enemyConfig != null)
            {
                GameManager.Instance.AddGold(_enemyConfig.goldReward);
            }
            
            base.Die(killer);
        }
    }
}
```
